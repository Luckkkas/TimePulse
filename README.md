⏱️ TimePulse

Um cronômetro moderno e minimalista desenvolvido com HTML, CSS e JavaScript.

🚀 Funcionalidades

- Iniciar o cronômetro.
- Pausar a contagem.
- Reiniciar o cronômetro.
- Registrar marcações de tempo (voltas).
- Interface moderna e responsiva.

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

🎨 Interface

O projeto possui um design minimalista com tema escuro, detalhes em azul e efeitos de interação.

📚 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de JavaScript, manipulação do DOM, eventos e controle de tempo.

💻 Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo "index.html" com o Live Server.
